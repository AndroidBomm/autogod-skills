# AutoGOD 示例代码（可运行）

配套文档技能：`auto-god-docs`（API 说明、脚本语法、模块开发、踩坑记录）。
本技能只放**可运行源码**，按作者原始目录组织，目录名就是 API 命名空间。

## 目录结构

```
SKILL.md
examples/<模块>/<序号.用途>.js|xml|java|txt|c
assets/base64/*.b64          18 个小素材（base64）
assets/restore-assets.ps1    一键还原素材
```

## 怎么用

1. 按模块进目录看文件名——文件名本身就是用途（如 `$act - 动作手势/01.获取权限.js`）。
2. 直接读文件全文，整段抄进脚本，或改几行参数。
3. 在本机运行 AutoGOD 脚本（或 adb push 到手机后再跑）；路径都按脚本所在环境的相对/设备路径写，**复制进工程时注意改路径**。
4. 需要图片 / 音频 / dex / jar / xlsx 素材的示例，先还原素材（见下）。

## 素材还原

18 个小于 60 KB 的素材已用 base64 内嵌在 `assets/base64/`，在技能根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File assets\restore-assets.ps1
```

- 每个 `.b64` 首行 `#path:` 是还原到技能根下的相对位置，`#sha256:` 用于校验，已存在的文件不会被覆盖。
- 另有 18 个 ≥60 KB 的二进制（大尺寸测试图、`.so`、演示 `.mp4`）没有内嵌，需要时从
  `H:\skill\auto-god-docs-backup-20261115.zip` 的 `examples/<模块>/` 里取。
