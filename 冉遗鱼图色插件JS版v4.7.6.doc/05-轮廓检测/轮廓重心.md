##### 简要描述

- 获取轮廓重心

##### 方法名
- ` getContoursMoments `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|img1 |是  |Mat | 二值化图片 |
|mode| 否  |int |同 GetContours函数  默认0 |
|method| 否  |int |同 GetContours函数 默认2 |
|contoursIndex |否  |int[] |要绘制的轮廓的引索数组 默认  nil  引索的筛选可以从其他轮廓函数返回的信息中提取,只要mode和method 一样,返回的数组信息都是一对一相对应的;比如, 轮廓重心返回的数组 和 轮廓长度返回数组是一样大小的, 轮廓重心[5] 和 轮廓长度[5]是同一个轮廓的信息|
##### 返回值说明 

|类型|说明|
|:-----  |:-----|
|Point[]或者null  | 返回所有轮廓的重心坐标数组 或者   null  |

##### 代码示例
```javascript
    //二值化图片
    let srcMat=imageHandler.readResMat("轮廓提取.png");
    //获取最外层轮廓的重心
    let result=imageHandler.getContoursMoments(srcMat,0,2,null);
    if (result) {
        //复制一份原图
        let tempMat = imageHandler.copyTo(srcMat, null);

        for (let i = 0; i < result.length; i++) {
            //画出重心
            let temp2 = imageHandler.drawCircle(tempMat, result[i].x, result[i].y, 2);
            imageHandler.recycle(tempMat);
            tempMat = temp2;
        }
        logd(imageHandler.saveMat(tempMat, "/storage/emulated/0/Pictures/tempMat.png"));
        //回收
        imageHandler.recycle(tempMat);

    }else {
        logd("没有轮廓信息")
    }
    //回收
    imageHandler.recycle(srcMat);
```
