##### 简要描述

- 获取连通域图片

##### 方法名
- ` connectedComponentsWithMat `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |二值化图片   |
|indexArr |否  |int[] |引索值数组 可从connectedComponentsWithStats结果的index属性获得   |
|connectivity |否  |int |领域类型 4 或 8, 默认8领域 |

##### 返回值说明 

|类型|说明|
|:-----  |:-----|
|null或Mat   |null或者图片  |

##### 代码示例

```javascript
    //截图或者读取图片
    let srcMat=imageHandler.readResMat("连通域.png");

    //虽然已经是个二值化图片,但为了防止误导,还是做了一下二值化
    let bit2=imageHandler.binaryzationMat(srcMat,127);
    //获取连通域状态信息
    let stats=imageHandler.connectedComponentsWithStats(bit2,4);
    if(stats){
        //打印所有
        logd(JSON.stringify(stats));
        //获取白点面积最大的目标
        let maxArea=0;
        let index=0;
        for (let i = 0; i < stats.length; i++) {
            if(stats[i].whiteArea>maxArea){
                maxArea=stats[i].whiteArea;//更新最大面积
                index=stats[i].index; //记录索引
            }
        }
        //获取最大白色面积的目标图片
        let bit3=imageHandler.connectedComponentsWithMat(bit2,[index],4);
        //保存图片
        logd(imageHandler.saveMat(bit3,"/storage/emulated/0/Pictures/bit3.png"));
        imageHandler.recycle(bit3);
    }


    imageHandler.recycle(srcMat);


```
