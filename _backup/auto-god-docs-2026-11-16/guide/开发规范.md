## 二、XML 布局规范

### 2.1 根节点

```xml
<ui>
    <!-- 布局内容 -->
</ui>
```

### 2.2 布局容器

| 标签 | 说明 | 关键属性 |
|------|------|----------|
| `<linear>` | 线性布局 | `dir="v"` 垂直, `dir="h"` 水平 |
| `<frame>` | 帧布局/绝对布局 | 无方向 |
| `<scroll>` | 滚动布局 | 同上 |
| `<list>` | 列表布局 | `items`, `select` |

### 2.3 尺寸属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `w` | 宽度 | `"wrap"`, `"max"`, `"0dp"`, `"200dp"` |
| `h` | 高度 | `"wrap"`, `"max"`, `"40dp"`, `"200dp"` |
| `weight` | 权重 | `"1"`, `"2"` |

### 2.4 布局属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `margin` | 外边距 | `"8"` 或 `"8,16"`（逗号分隔） |
| `marginTop` | 上边距 | `"16"` |
| `marginLeft` | 左边距 | `"8"` |
| `marginRight` | 右边距 | `"8"` |
| `marginBottom` | 下边距 | `"8"` |
| `padding` | 内边距 | `"16"` 或 `"10,20,10,15"`（逗号分隔） |
| `gravity` | 重心 | `"center"`, `"left"`, `"right"` |

### 2.5 组件属性

| 属性 | 说明 | 示例 |
|------|------|------|
| `id` | 组件 ID | `"btn1"`, `"inputName"` |
| `bg` | 背景色 | `"#FFFFFF"`, `"#4CAF50"` |
| `textColor` | 文字颜色 | `"#000000"`, `"#FFFFFF"` |
| `color` | 文字颜色（替代 textColor） | `"#333333"` |
| `textSize` | 文字大小 | `"16"`, `"18"`（可带 `dp` 单位，如 `"16dp"`） |
| `visibility` | 可见性 | `"visible"`, `"gone"`, `"hidden"` |

> ⚠️ **注意**：`visibility` 属性在 XML 中不生效，必须在 JS 中用 `view.setVisibility($ui.GONE)` 控制。

## 三、组件标签

### 3.1 按钮

```xml
<button id="btn1" text="点击" bg="#4CAF50" textColor="#FFFFFF" textSize="16" />
```

### 3.2 文本

```xml
<text text="标签:" textSize="16" color="#333333" />
```

### 3.3 输入框

```xml
<input id="input1" hint="请输入" type="text" />
```

- `type` 取值：`text`, `number`, `password`

### 3.4 下拉框

```xml
<drop id="drop1" items="选项1,选项2,选项3" select="0" />
```

### 3.5 图片

```xml
<img id="img1" src="widget://image/logo.png" />
```

### 3.6 复选框

```xml
<checkbox id="check1" text="同意协议" checked="true" />
```

### 3.7 工具栏

```xml
<toolbar id="mainToolbar" title="标题" bg="#1976D2" textColor="#FFFFFF" />
```

### 3.8 AppBar（必须添加，消除全局脚本警告）

```xml
<appbar id="mAppbar" w="max" />
```

> ⚠️ 每个界面都必须添加 `<appbar id="mAppbar" w="max" />`，否则会报"未找到控件:mAppbar"错误。

## 四、JavaScript API

### 4.1 入口函数

```javascript
// 加载布局文件并显示
var ui = $ui.layout("main.xml");
ui.show();

// 初始化代码...
```

### 4.2 组件获取

```javascript
// 通过 ID 获取组件
var btn = ui.id("btnId");
var input = ui.id("inputId");

// ⚠️ 注意：方法名是 id()，不是 ids()
```

### 4.3 组件操作

| 操作 | 代码 |
|------|------|
| 获取文本 | `input.text()` 或 `input.getText()` |
| 设置文本 | `input.text("内容")` 或 `input.setText("内容")` |
| 获取下拉框选中项 | `drop.getSelect()` → 返回索引 `0, 1, 2...` |
| 设置下拉框选中项 | `drop.setSelect(1)` |

### 4.4 视图操作

| 操作 | 代码 |
|------|------|
| 显示组件 | `view.setVisibility($ui.VISIBLE)` |
| 隐藏组件 | `view.setVisibility($ui.GONE)` |
| 添加视图 | `container.addView(view)` |
| 移除视图 | `view.remove()` |
| 清除子视图 | `container.removeAll()` |

### 4.5 动态创建视图（重要！）

```javascript
// ❌ 错误方式——$ui.create() 不存在！
// var textView = $ui.create("text");

// ✅ 正确方式——使用 $ui.layout() 传入 XML 模板字符串
let itemUi = $ui.layout(`
<ui>
    <text id="label" text="动态文本" w="100" h="50" bg="#4CAF50" />
</ui>
`);
let textView = itemUi.id("label");
container.addView(textView);

// ✅ 动态属性拼接
var x = 100;
var lineUi = $ui.layout(`<ui><view id="vLine" w="1" h="500" marginLeft="` + x + `" /></ui>`);
var vLine = lineUi.id("vLine");
container.addView(vLine);

// ⚠️ 注意：视图被添加到容器后，不能再添加到其他容器（Android 机制）
// 如果需要重复添加，必须每次重新用 $ui.layout() 创建新的视图
```

### 4.6 屏幕尺寸获取

```javascript
// ✅ 正确方式
var screenWidth = $screen.getWidth();
var screenHeight = $screen.getHeight();

// ❌ 错误方式
// $device.info.screen.width;  // 不存在！
```

### 4.7 事件绑定

```javascript
// 按钮点击事件
ui.id("btn").click(function() {
    // 处理点击
});

// 下拉框选择变化
ui.id("drop").onCheck(function(value, index) {
    // index: 0, 1, 2...
});

// 点击事件（带坐标）
touchLayer.click(function(e) {
    var x = e.x;
    var y = e.y;
});
```

### 4.8 定时器

```javascript
// 延迟执行（毫秒）
setTimeout(function() {
    // 代码
}, 1000);

// 循环执行
var intervalId = setInterval(function() {
    // 代码
}, 1000);

// 停止循环
clearInterval(intervalId);
```

## 五、悬浮窗

### 5.1 创建系统级悬浮窗

```javascript
// ⚠️ 创建系统级悬浮窗用 $floaty.newSys()，应用级用 $floaty.newApp()，两者 API 相同
//    $floaty.window() 不存在，不要用
var floaty = $floaty.newSys(`
<ui>
<frame w="200dp" h="300dp" bg="#FFFFFF">
<linear dir="v" w="max" h="max" gravity="center">
<text text="悬浮窗内容" textSize="16" />
</linear>
</frame>
</ui>
`);
floaty.setXY(100, 200);  // 设置位置
floaty.setWH(200, 300);  // 设置宽高
```

### 5.2 获取控件

```javascript
var btn = floaty.id("btnId");
btn.click(function() {
    // 处理点击
});
```

### 5.3 关闭悬浮窗

```javascript
floaty.close();
```

### 5.4 隐藏悬浮窗（不销毁）

```javascript
// 移出屏幕——实现隐藏效果
floaty.setXY(-2000, -2000);
```

## 六、文件操作

### 6.1 路径操作

```javascript
// 拼接路径
var filePath = $file.join($file.sd(), "folder", "file.txt");

// 判断是否是目录
var isDir = $file.isDir("path/to/folder");

// 创建目录
$file.mkDir("path/to/folder");

// 列出目录文件
var files = $file.listDir("path/to/folder");

// 判断文件是否存在
var exists = $file.exist("path/to/file.txt");
```

### 6.2 读取文件

```javascript
var content = $file.read("path/to/file.txt");
```

### 6.3 写入文件（参数顺序：内容在前，路径在后！）

```javascript
// ⚠️ 参数顺序：$file.write(content, path)——内容在前，路径在后！
$file.write("文件内容", "path/to/file.txt");

// 写入 JSON 数据
$file.write(JSON.stringify(data), filePath);
```

## 十、常见错误

### ❌ 错误写法 vs ✅ 正确写法

| 错误写法 | 正确写法 | 说明 |
|---------|---------|------|
| `<LinearLayout>` | `<linear>` | 标签名全部小写 |
| `android:layout_width="match_parent"` | `w="max"` | 属性名使用缩写 |
| `orientation="vertical"` | `dir="v"` | 方向属性用 dir |
| `background="#FFFFFF"` | `bg="#FFFFFF"` | 背景色用 bg |
| `textColor="#000000"` | `color="#000000"` | 文字颜色用 color |
| `$ui.create("text")` | `$ui.layout(\`<ui>...\</ui>\`)` | 动态创建视图用 layout |
| `$file.write(path, content)` | `$file.write(content, path)` | 参数顺序：内容在前 |
| `$floaty.window(xml)` | `$floaty.newSys(xml)` | 悬浮窗用 newSys |
| `view.setVisibility("gone")` | `view.setVisibility($ui.GONE)` | 可见性用常量 |
| `ui.ids("xxx")` | `ui.id("xxx")` | 方法名是 id 不是 ids |

---

## 十一、注意事项

1. **不要混淆**：AutoGOD ≠ Android ≠ Web ≠ HTML ≠ Android XML
2. **属性名不同**：`layout_width` → `w`, `orientation` → `dir`
3. **大小写敏感**：JavaScript 区分大小写
4. **ID 唯一性**：同一界面中 ID 不能重复
5. **必须加 `<appbar id="mAppbar"/>`**：消除全局脚本警告
6. **动态创建视图**：必须用 `$ui.layout()` 模板字符串，不能用 `$ui.create()`
