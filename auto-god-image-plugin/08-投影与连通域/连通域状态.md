##### 简要描述

- 获取连通域,与轮廓类似,但没有内外轮廓之分,白色相连的地方被视为是一个整体

##### 方法名
- ` connectedComponentsWithStats `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |二值化图片   |
|connectivity |否  |int | 领域类型 4 或 8, 默认8 表示8连通,区别见备注  |

##### 返回值说明

|类型|说明|
|:-----  |:-----|
|null或ConnectedComponents[]   |返回 null 或者 ConnectedComponents数组<br>ConnectedComponents对象 包含一下信息<br>index:引索值 为connectedComponentsWithMat提供的<br/> center:中心的point<br/>rect:区域<br/>whiteArea:白点的面积(像素点为单位)<br/>rectArea:矩形围成的面积<br/>  |

##### 代码示例
```javascript
    //截图或者读取图片
    let srcMat=imageHandler.readResMat("连通域.png");

    //虽然已经是个二值化图片,但为了防止误导,还是做了一下二值化
    let bit2=imageHandler.binaryzationMat(srcMat,127);
    //获取连通域状态信息
    let stats=imageHandler.connectedComponentsWithStats(bit2,4);
    if(stats){
        //打印所有
        logd(JSON.stringify(stats));
        for (let i = 0; i < stats.length; i++) {
            logd("索引值:"+stats[i].index);
            logd("中心点:"+JSON.stringify(stats[i].center));
            logd("区域:"+JSON.stringify(stats[i].rect));
            logd("白点面积:"+stats[i].whiteArea);
            logd("矩形围成面积:"+stats[i].rectArea);
        }
        //在图色画出位置
        let srcMat2 =imageHandler.copyTo(srcMat,null);
        let srcMat3;
        for (let i = 0; i < stats.length; i++) {
            srcMat3 =imageHandler.drawRect2(srcMat2,stats[i].rect);
            imageHandler.recycle(srcMat2);
            srcMat2=srcMat3;
        }
        //保存图片
        logd(imageHandler.saveMat(srcMat3,"/storage/emulated/0/Pictures/srcMat3.png"));
        imageHandler.recycle(srcMat3);
    }

    imageHandler.recycle(srcMat,bit2);

```
