#### 支持 **v5.0.0 及之后** 的版本

> ⚠️ **官方文档写的是「支持 v4.9.4 之后的版本」，但这个说法容易误导。**
> 实测 **v4.9.4 的 `OperHandler.js` 里根本没有这 5 个方法**（只有旧的 `drawRectShow` /
> `drawCircleShow` / `drawPointShow` / `removeFloaty` / `releaseFloaty`），
> 到 **v5.0.0** 起全部换成这套新 API。所以请按 **v5.0.0+** 理解。

1. 要有**悬浮窗权限**
2. **无法在 root 模式下运行**
3. **所有悬浮窗方法都是异步的** —— 同时调用时**顺序不保证**。比如「绘制」和「清除」一起跑，
   可能先绘制再清除，也可能先清除再绘制。需要保证顺序时，中间加 `sleep`。
4. **密集计算时 UI 可能来不及清除** —— 例如 yolo 循环检测这种场景，UI 线程抢不到 CPU/GPU 资源，
   屏幕上的绘制会延迟消失。中间加 `sleep` 即可。

##### 新旧对照（v5.0.0 是破坏性更新）

| 旧（v4.9.4 及更早） | 新（v5.0.0+） |
|---|---|
| `drawRectShow(...)` / `drawRectShow2(...)` | `showRectOverlay(matches)` |
| `drawCircleShow(...)` | `showCircleOverlay(ps)` |
| `drawPointShow(...)` | `showCircleOverlay(ps)`（`ps` 里给半径 `r`） |
| `drawImageShow(...)` | `showImageOverlay(mat, x, y, w, h)` |
| `removeFloaty()`（只清绘制） | `clearOverlay()`（只清内容，保留窗口） |
| `releaseFloaty()`（清并释放） | `hideOverlay()`（删除窗口并释放图片） |

##### 备注

- 这是「悬浮窗（新）」系列，与 `15-屏幕绘制` 里的 `drawRectShow` / `drawCircleShow` / `drawPointShow`
  （悬浮窗（旧），**v5.0.0 已删除**）是**两套不同的 API**，不要混用。
- 新系列方法名统一以 `Overlay` 结尾：`showRectOverlay` / `showCircleOverlay` / `showImageOverlay` /
  `clearOverlay` / `hideOverlay`。
- 旧写法在 **v5.0.4 里会直接报「方法不存在」**，不是警告也不是降级。
