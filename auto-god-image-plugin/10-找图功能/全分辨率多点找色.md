##### 简要描述

- 在全分辨率找图基础上建立的全分辨率多点找色

##### 方法名
- ` findImgByColor `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |原图   |
|tempPath |是  |string |小图路径,例如 "myImg.jpg", "drawable/myImg.png"|
|color |否  |string |第一个点的颜色,同多点找色.如果为null将由程序自动筛选,返回的尽可能为中心的坐标,如需精确的请手动填写   |
|colorMulti |否  |string |其他颜色点  同多点找色  与color只要有一个为null 将由程序自动筛选   |
|threshold |否  |double |相似度 0~1.0,默认 0.9|
|sx |否  |int |起点x   |
|sy |否  |int |起点y   |
|ex |否  |int |终点x   |
|ey |否  |int |终点y   |
|count |否  |int |寻找数量 默认1个   |
|direction |否  |int |寻找方向 同多点找色|
##### 返回值说明

|类型|说明|
|:-----  |:-----|
|P_Color或null   |返回null 或者 P_Color对象,继承自Point <br/> P_Color.x  坐标x <br/>P_Color.y  坐标y <br/> P_Color.color1  第一个颜色字符串  亦可用于普通多点找色<br/>P_Color.color2 其他颜色字符串    亦可用于普通多点找色<br/>  |

##### 代码示例
```javascript
    //截图或者读取图片
    let srcMat=imageHandler.captureScreenMat();

    let temp=imageHandler.readResMat("qq.png");

    //模拟第一次运行
    console.time("1");
    let p=myFindColor();
    logd(p);
    logd("第一次耗时:"+console.timeEnd("1")+"ms");

    //模拟第二次运行
    console.time("2");
    let p2=myFindColor();
    logd(p2);
    logd("第二次耗时:"+console.timeEnd("2")+"ms");

    function myFindColor(){
        let point;
        if(imageHandler.getColorMap("qq.png")){ //如果已经提取过颜色,直接执行 findImgByColor
            point=imageHandler.findImgByColor(srcMat,"qq.png",null,null,0.9,550,300,789,505,1,1);
        }else  {
            //如果没有提取过颜色,先用较快的方法判断一下目标是否存在
            let p=imageHandler.findImgBySurfEx(srcMat,temp,1,1,550,300,789,505);
            if(p){
                point=imageHandler.findImgByColor(srcMat,"qq.png",null,null,0.9,550,300,789,505,1);
            }
        }
        return point;
    }
    imageHandler.recycle(srcMat,temp)
```
