##### 简要描述

- 获取二值化图像或者轮廓近似逼近后的多边形的角点坐标集合（v4.4）, 类似于approxPolyDP方法，approxPolyDP返回图形，而getApproxPolyDPPoint返回角度坐标集合

##### 方法名
- ` getApproxPolyDPPoint `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |二值化图像或者轮廓   |
|mode |否 |int |定义轮廓的检索模式(可选值0,1,2) 默认为0,<br/>0:只检测最外围轮廓,包含在外围轮廓内的内围轮廓被忽略; <br/>1:检测所有的轮廓,包括内围、外围轮廓,但是检测到的轮廓不建立等级关系,hierarchy向量内所有元素的第3、第4个分量都会被置为-1;<br/>2:检测所有的轮廓,但所有轮廓只建立两个等级关系,外围为顶层,若外围内的内围轮廓还包含了其他的轮廓信息,则内围内的所有轮廓均归属于顶层 |
|method |否 |int |定义轮廓的近似方法(可选值1,2) 默认为2; <br/>1:保存物体边界上所有连续的轮廓点到contours向量内;<br/>2:仅保存轮廓的拐点信息,把所有轮廓拐点处的点保存入contours向量内,拐点与拐点之间直线段上的信息点不予保留;|
|contoursIndex |否 |int[] |要获取的轮廓的引索数组,默认null,引索的筛选可以从其他轮廓函数返回的信息中提取,只要mode和method 一样,返回的数组信息都是一对一相对应的<br/>比如, 轮廓重心返回的数组 和 轮廓长度返回数组是一样大小的, 轮廓重心[5] 和 轮廓长度[5]是同一个轮廓的信息|
|epsilon |否  |int |轮廓近似逼近阈值 默认为 -1 表示目标周长的百分之一为阈值|

##### 返回值说明

|类型|说明|
|:-----  |:-----|
|Point[][] 或者 null |二维数组坐标（每个轮廓一个维度）或者 null|

##### 代码示例
```javascript
    //读取一张二值化图片
    let srcMat=imageHandler.readResMat("F4.png");

    //获取轮廓角点
    let points=imageHandler.getApproxPolyDPPoint(srcMat,0,2);
    if(points){
        for (let i = 0; i < points.length; i++) {
            logd("第"+i+"个轮廓角点坐标：",JSON.stringify(points[i]));
        }
    }
    //回收
    imageHandler.recycle(srcMat);

```
