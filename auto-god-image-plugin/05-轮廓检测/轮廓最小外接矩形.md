##### 简要描述

- 获取轮廓的最小外接矩形

##### 方法名
- ` getContoursMinRect`
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |二值化图   |
|mode |否 |int |定义轮廓的检索模式(可选值0,1,2) 默认为0,<br/>0:只检测最外围轮廓,包含在外围轮廓内的内围轮廓被忽略; <br/>1:检测所有的轮廓,包括内围、外围轮廓,但是检测到的轮廓不建立等级关系,hierarchy向量内所有元素的第3、第4个分量都会被置为-1;<br/>2:检测所有的轮廓,但所有轮廓只建立两个等级关系,外围为顶层,若外围内的内围轮廓还包含了其他的轮廓信息,则内围内的所有轮廓均归属于顶层 |
|method |否 |int |定义轮廓的近似方法(可选值1,2) 默认为2; <br/>1:保存物体边界上所有连续的轮廓点到contours向量内;<br/>2:仅保存轮廓的拐点信息,把所有轮廓拐点处的点保存入contours向量内,拐点与拐点之间直线段上的信息点不予保留;|
|contoursIndex |否 |int[] |轮廓的引索数组,默认null,引索的筛选可以从其他轮廓函数返回的信息中提取,只要mode和method 一样,返回的数组信息都是一对一相对应的<br/>比如, 轮廓重心返回的数组 和 轮廓长度返回数组是一样大小的, 轮廓重心[5] 和 轮廓长度[5]是同一个轮廓的信息|

##### 返回值说明

|类型|说明|
|:-----  |:-----|
|Point[][]或者 null|Point二维数组或者 null （因为是旋转的矩形，所有返回的每组是矩形的四个点（顺时针）） |

##### 代码示例
```javascript


    //截图或读取图片
    let srcMat=imageHandler.readResMat("yang.png");

    //颜色范围提取 这里提取了背景
    let inRangeMat = imageHandler.inRange(srcMat, [14,77,34],[199,255,255]);

    //反向二值化
    let bin=imageHandler.binaryzationMat(inRangeMat,127,255,1);

    //获取轮廓最小矩形
    let pointsArr=imageHandler.getContoursMinRect(bin,0,2,null);

    if(pointsArr){
         //画出来
        for (let i = 0; i < pointsArr.length; i++) {
            //logd(pointsArr[i][0].x,pointsArr[i][0].y)
            srcMat=imageHandler.drawLines2(srcMat,pointsArr[i],"#FF0000",2,true);
        }
    }
    let r= imageHandler.saveMat(srcMat,"/storage/emulated/0/Pictures/1.png","png",100);
    logd("保存结果:"+r);
    imageHandler.recycleAllMat();

```
