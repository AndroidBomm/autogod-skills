##### 简要描述

- 将图片变成哈希值,使用哈希值快速匹配
- 假如拿一张图片与几千上万张图片对比查找相似的图片,将图片缩放成统一大小,比如8*8大小,经过离散余弦变化、二值化等操作,把图片变成64位01组成的字符串,然后使用汉明距离算法进行相似度匹配,以达到快速过滤的作用


##### 方法名
- ` pHashCode `
##### 参数

|参数名|必选|类型|说明|
|:----    |:---|:----- |-----   |
|mat |是  |Mat |图片   |
|dctSize |否  |int |离散余弦变换大小,可以理解为缩放后的图片大小 用于余弦计算 默认32 即32*32大小 可以选值 8,16,32 值越小速度越快   |
|ROISize |否  |int |对余弦的结果取值大小,默认8,即 8*8大小   |

##### 返回值说明

|类型|说明|
|:-----  |:-----|
|string   |01组成的字符串 例如 "1010110000010010010000010100001001001000010010000000000100100110"  |

##### 代码示例
```javascript
     //假如读取图片一万张
    let mats=imageHandler.readResMat("1.png|3.png|4.png|5.png");

    //用于保存哈希值,哈希值也可以是提前保存于txt里的
    let codeArr=[]
    //计算哈希值
    for (let i = 0; i < mats.length; i++) {
        codeArr[i]= imageHandler.pHashCode(mats[i]);
    }

    //目标图片
    let mat=imageHandler.readResMat("4.png");
    //计算哈希值
    let value= imageHandler.pHashCode(mat);

    for (let i = 0; i < codeArr.length; i++) {
        //计算汉明距离
        let distance=imageHandler.hanMingDistance(value,codeArr[i]);
        logd("相似度:",(1-(distance/value.length)));
    }
    //回收
    imageHandler.recycle(mats,mat);

```
