# $module - 模块化编程

- 更新时间:2026-06-22 19:00:00

AIGame 采用模块化编程作为主流形式，支持灵活的模块导入导出机制。

---

## 快速开始

### 编写模块（导出）

直接导出函数即可，无需关键字

```javascript
let show = function () {
    sleep(2000);
    toast("我是模块");
    sleep(5000);
}

// 导出函数（注意：不要写成 show()，这是调用函数）
show;
```

### 导入模块

使用 `require()` 函数导入模块，`require` 是全局函数，无需加 `$` 前缀

```javascript
// 导入模块
let show = require("show");

// 使用模块
show();  // 现在可以调用函数了
```

## 模块导出方式

### 函数模块导出

导出单个函数

```javascript
// 定义函数
let add = function(a, b) {
    return a + b;
}

// 导出函数（直接写函数名，不要加括号）
add;
```

### 对象模块导出

导出对象数据

```javascript
// 定义对象
let obj = {
    name: "张三",
    age: 18,
    sex: "男"
}

// 导出对象
obj;
```

### 类模块导出

导出构造函数或类

```javascript
// 定义类
function MyClass() {
    this.name = "张三";
    this.age = 18;

    this.show = function() {
        alert("我的信息", this.name + "\n" + this.age);
    }
}

// 导出类
MyClass;
```

## 导出多个模块

使用对象方式导出多个函数或变量

```javascript
// 定义多个模块
let show = function() {
    sleep(2000);
    toast("我是模块1");
    sleep(5000);
}

let show2 = function() {
    sleep(2000);
    toast("我是模块2");
    sleep(5000);
}

// 导出多个模块——合并成一个对象
let modules = {
    show: show,
    show2: show2
}

modules;  // 导出对象，包含多个模块
```

### 使用导出的多个模块

```javascript
// 导入模块对象
let modules = require("myModules");

// 使用模块
modules.show();   // 调用第一个函数
modules.show2();  // 调用第二个函数
```

## 目录结构

### 模块路径规则

- **同级目录**：`require("模块名")`
- **子目录**：`require("目录名/模块名")`
- **相对路径**：支持相对路径导入

```
project/
├── main.js
├── modules/
│   ├── utils.js
│   └── network.js
└── libs/
    └── crypto.js
```

```javascript
// 导入模块示例（路径相对于项目根目录，不要加斜杠开头）
let utils = require("modules/utils");
let network = require("modules/network");
let crypto = require("libs/crypto");
```

## 注意事项

### 常见错误

1. **错误导出函数**：
   ```javascript
   add();  // ❌ 错误：这是调用函数，不是导出
   add;    // ✅ 正确：导出函数本身
   ```

2. **路径错误**：
   ```javascript
   require("/modules/show");  // ❌ 错误：不要使用绝对路径
   require("modules/show");   // ✅ 正确：使用相对路径（相对于项目根目录）
   ```

### 最佳实践

- ✅ 使用清晰的模块名
- ✅ 添加适当的注释说明
- ✅ 合理组织模块目录结构
- ✅ 避免循环依赖
- ✅ 一个模块专注于一个功能

## 完整示例

### 数学工具模块 (math.js)

```javascript
// 定义数学函数
let add = function(a, b) { return a + b; }
let subtract = function(a, b) { return a - b; }
let multiply = function(a, b) { return a * b; }
let divide = function(a, b) { return b !== 0 ? a / b : 0; }

// 导出所有函数
let math = {
    add: add,
    subtract: subtract,
    multiply: multiply,
    divide: divide
}

math;
```

### 使用数学模块

```javascript
let math = require("math");

let result1 = math.add(10, 5);        // 15
let result2 = math.multiply(3, 4);    // 12
let result3 = math.divide(20, 5);     // 4

toast("计算结果: " + result1 + ", " + result2 + ", " + result3);
```
