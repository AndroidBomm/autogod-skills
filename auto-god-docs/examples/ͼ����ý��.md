# 代码示例 - 图像与媒体

更新时间:2026-06-22 19:00:00

## $canvas 画布

```javascript
// 创建画布
let canvas = $canvas.create(500, 500);

// 创建画笔
let paint = $canvas.paint();
paint.setColor($color.RED);

// 绘制矩形
canvas.drawRect(30, 30, 400, 400, paint);

// 绘制文本
paint.setTextSize(25);
canvas.drawText("Hello", 170, 145, paint);

// 显示画布图片
canvas.show();

// 保存图片
canvas.save("/sdcard/画布.png");

// 在布局中显示
ui.id("mImg").setImg(canvas.getBitmap());
```

## $img 图片操作

```javascript
// 读取图片
let img = $img.read("/sdcard/photo.png");

// 裁剪
let clip = $img.clip(img, 100, 100, 300, 300);

// 缩放
let resize = $img.resize(img, 200, 200);

// 旋转
let rotate = $img.rotate(img, 90);

// 灰度化
let gray = $img.gray(img);

// 保存
$img.save(clip, "/sdcard/clip.png");

// 释放内存
img.recycle();
```

## $media 媒体播放

```javascript
// 播放音频
$media.play("/sdcard/music.mp3");

// 暂停
$media.pause();

// 继续
$media.resume();

// 停止
$media.stop();

// 设置音量 0-1
$media.setVolume(0.5);

// 获取播放状态
let isPlaying = $media.isPlaying();
```
